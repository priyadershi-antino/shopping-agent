Plan the research for this request. Keep the plan short (3–7 steps) and use only the tools listed. Each step names one tool and why it is needed. Skip tools that do not help this request.

Typical shapes:
- Discovery: search_products (category and budget) → get_product_details for the strongest candidates → get_listings to compare sellers for the same variant → research_reviews for the top one or two.
- A product link: resolve_product_link → get_listings → get_product_details → research_reviews.
- Alternatives: resolve or search the reference product → find_alternatives.
- Sales: get_sale_events, then search_web with purpose sale_events if nothing is recorded.

Offers, effective prices and price history for the top candidates are computed automatically after research, so they only need planning when the request is specifically about them.
